# Partial Gravity Bioreactor Simulation

A computational simulation of a partial gravity bioreactor system designed to model biological behavior under reduced gravity conditions.

🏆 Developed as a **Senior Design Project (1st Place Winner)**

---

## Overview

This project focuses on simulating how cells and biological systems behave in environments where gravity is altered, such as in space or rotating bioreactor systems.

The model incorporates:

* Rotational dynamics
* Gravity vector manipulation
* Mathematical modeling of system behavior


## Key Features

* Simulation of partial gravity conditions
* Mathematical modeling of rotational systems
* Data visualization of system behavior
* Modular code structure for experimentation


## Applications

* Space biology research
* Tissue engineering
* Bioreactor design optimization
* Microgravity simulation studies
